# MazimaCheck

Check a photo or video before you trust it. MazimaCheck estimates whether an image is AI-generated, shows where its suspicion is highest, boxes and checks faces, and tests whether the verdict survives chat-app compression. Everything runs in your browser: nothing is uploaded.

Live at https://mazimacheck.dev (new version at /v2/).

The How it works page explains the verdicts and how to read them.
